# Itqān

Application d’apprentissage de la lecture arabe centrée sur la précision puis la fluidité.

## Principes

VOIR → DÉCOMPOSER → PRONONCER → FLUIDIFIER

L’application n’est pas un cours général d’arabe, de vocabulaire, de grammaire ou de Tajwid.

## Lancer localement

```bash
npm install
npm run dev
```

## État de cette base

- Accueil : implémenté
- Parcours : implémenté
- Navigation : implémentée
- Révision / Sources / Profil : structure initiale
- Contenu arabe actif : aucun
- Garde-fou de vérification des sources : implémenté
