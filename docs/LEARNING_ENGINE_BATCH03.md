# Itqān — Learning Engine Batch 03

Ce lot construit le moteur pédagogique indépendant de l'interface.

- résolution de l'arabe uniquement par `itemId` depuis les manifests contrôlés ;
- blocage des items ambigus ou insuffisamment vérifiés ;
- états Découverte → Progression → Consolidation → Maîtrise → Excellence ;
- une performance unique ne peut jamais produire Maîtrise ;
- révision priorisée par erreurs récentes et manque de stabilité ;
- chronométrage séparant préparation, lecture réelle et durée totale ;
- interface fournisseur pour une future reconnaissance vocale ;
- diagnostic précis de voyelle/Sukūn/Shaddah interdit tant qu'une couche validée Itqān ne le justifie pas.

Les seuils de maîtrise présents dans le code sont des valeurs de conception calibrables après tests utilisateurs.
